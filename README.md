# ◈ Phantom OSINT

أداة احترافية لإنشاء وإدارة ملفات OSINT المرئية.
## تحميل
```bash
git clone https://github.com/PhantomByte313/PhantomOsint.git
```

## تشغيل
```bash
pip install PyQt6
python3 main.py
```

## المميزات
- 50+ حقل بيانات لكل هدف
- مخطط رسومي تفاعلي (Node Graph)
- قاعدة بيانات SQLite محلية (~/.phantom_osint/)
- دعم صور الأهداف
- تصدير JSON
- بحث فوري
- تصنيف مستوى التهديد
